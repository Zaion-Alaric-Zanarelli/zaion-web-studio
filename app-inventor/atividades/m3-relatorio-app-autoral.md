# 📱 Avaliação – Projeto Autoral (App Inventor)

## Modalidade
Atividade em **grupo**.

## Forma de Entrega
O trabalho deve ser **publicado no GitHub do grupo**.

As respostas e o relatório devem ser:

- claros
- objetivos
- bem organizados

⚠️ **Observações importantes**

- O trabalho deve ser **colaborativo**.
- Caso seja identificado que **apenas um aluno realizou a postagem**, o conceito do grupo poderá ser **reduzido**.
- Alunos que **não colaborarem com o desenvolvimento do projeto** poderão ter **redução no conceito individual**.
- Projetos **iguais ou muito semelhantes entre grupos** também poderão ter **redução no conceito**.

💡 Cada grupo deve propor **uma ideia própria de aplicativo**.

---

# 🎯 Objetivo do Projeto

Este é um **Projeto Autoral**.

O objetivo é desenvolver um **aplicativo original**, utilizando os conhecimentos aprendidos nos projetos anteriores documentados no arquivo: **m2-relatorio-app.md**


O aplicativo deve reunir **a maioria dos conceitos estudados na apostila**, como:

- construção de interface (Design)
- programação com blocos
- interação com o usuário
- organização lógica do aplicativo

# 📚 Bases Tecnológicas Envolvidas

Esta atividade trabalha competências importantes da área de **Informática para Internet**.

## Desenvolvimento de Aplicativos

Os alunos devem aplicar conhecimentos como:

- criação de **interfaces gráficas**
- programação utilizando **blocos no App Inventor**
- organização lógica de um aplicativo
- interação com o usuário

## Desenvolvimento de Projetos

Também é importante desenvolver habilidades como:

- planejamento de uma ideia
- resolução de problemas
- criatividade na construção de soluções tecnológicas

## Documentação de Software

No desenvolvimento de sistemas é fundamental **documentar o projeto**, explicando:

- o objetivo do aplicativo
- como ele funciona
- quais recursos foram utilizados
- como o sistema foi desenvolvido

A documentação permite que outras pessoas **entendam e reproduzam o projeto**.

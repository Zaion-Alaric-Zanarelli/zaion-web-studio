# 📌 1. Apresentação do Projeto

O projeto consiste na criação de um site simples utilizando apenas **HTML 4.0 (sem CSS)**, com o objetivo de informar e conscientizar sobre a importância da proteção dos animais.

- 📅 **Data de apresentação:** 07/04/2026  
- 👥 **Modalidade:** Em dupla  

---

# 🧠 2. Sobre o Tema

O **Abril Laranja** é um movimento internacional dedicado à conscientização e prevenção da crueldade contra os animais. Durante esse mês, diversas campanhas são realizadas para informar a população sobre maus-tratos, abandono e a importância do respeito aos animais.

## Por que esse tema é importante?

- Promove empatia e responsabilidade  
- Incentiva a adoção responsável  
- Combate a violência contra os animais  
- Divulga leis de proteção animal  

---

# 🎯 3. Objetivos do Projeto

- Criar um site informativo em HTML  
- Desenvolver habilidades básicas de programação  
- Trabalhar em equipe  
- Pesquisar e organizar informações  
- Conscientizar outras pessoas  

---

# 📂 4. Estrutura do Site

O site deve conter as seguintes páginas (ou seções):

## 🏠 Página Inicial (index.html)

- Título do projeto  
- Breve explicação sobre o Abril Laranja  
- Nome dos alunos  

## 📢 Campanhas

- Explicar campanhas de conscientização  
- Exemplos de ações (adoção, denúncias, redes sociais)  

## 🐶 ONGs

- Apresentar ONGs que protegem animais  
- Explicar o papel delas  

## ⚖️ Leis

- Informar sobre leis contra maus-tratos  
- Exemplo: Lei de proteção animal no Brasil  

## ℹ️ Sobre

- Explicar o objetivo do site  
- Falar sobre o projeto escolar  
- Autores  
- Professores  
- Dados do curso
- Referências das fontes usadas no projeto (colocar o nome do site e o link)

# 🧩 5. Planejamento do Site (Passo a Passo)

## Etapa 1 – Pesquisa

- Buscar informações confiáveis sobre o tema  
- Separar conteúdo para cada página  

## Etapa 2 – Organização

- Dividir tarefas entre a dupla  
- Definir quem faz cada página  

## Etapa 3 – Estrutura HTML

Criar os seguintes arquivos:

- `index.html`  
- `campanhas.html`  
- `ongs.html`  
- `leis.html`  
- `sobre.html`  

## Etapa 4 – Criação do Código

Exemplo básico de HTML 4.0:

```
<html>
<head>
<title>Abril Laranja</title>
</head>

<body>

<h1>Abril Laranja</h1>

<p>Este site tem como objetivo conscientizar sobre a proteção dos animais.</p>

<a href="campanhas.html">Campanhas</a><br>
<a href="ongs.html">ONGs</a><br>
<a href="leis.html">Leis</a><br>
<a href="sobre.html">Sobre</a>

</body>
</html>
```

## Etapa 5 – Navegação

- Criar links entre todas as páginas  
- Facilitar o uso do site  

## Etapa 6 – Revisão

- Corrigir erros  
- Verificar ortografia  
- Testar todos os links

# 🧪 9. Exemplo de código HTML desejado

```
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN">
<html>
<head>
    <title>HTML 4.0 Sem CSS</title>
</head>

<body bgcolor="#f0f0f0">

    <!-- Layout com tabela -->
    <table width="100%" border="1">

        <!-- TOPO -->
        <tr bgcolor="#cccccc">
            <td colspan="2" align="center">
                <h1>Meu Site</h1>
                <p>HTML 4.0 sem CSS</p>
            </td>
        </tr>

        <!-- MENU + CONTEÚDO -->
        <tr>

            <!-- MENU -->
            <td width="20%" valign="top" bgcolor="#dddddd">
                <a href="#">Início</a><br>
                <a href="#">Sobre</a><br>
                <a href="#">Contato</a>
            </td>

            <!-- CONTEÚDO -->
            <td width="80%" valign="top">
                <h2>Bem-vindo</h2>
                <p>Layout feito com tabela.</p>
            </td>

        </tr>

        <!-- RODAPÉ -->
        <tr bgcolor="#cccccc">
            <td colspan="2" align="center">
                Rodapé
            </td>
        </tr>

    </table>

</body>
</html>
```

# 🌐 Atividade: Construção de Site

## 🎯 Objetivo
Desenvolver um site informativo sobre uma **profissão da área de informática**, aplicando conceitos de HTML e CSS.

---

## 👥 Modalidade
- Atividade em **dupla**

---

## 📅 Data de Entrega
- **02/06/2026**
- Entregar no **GitHub do grupo**, dentro da pasta da dupla

---

## 📁 Organização no GitHub

A organização do repositório é **muito importante**.

O projeto deve:

- Mostrar a **evolução do desenvolvimento** (vários commits)
- Demonstrar **colaboração entre os integrantes**
- Ter arquivos e pastas bem organizados

---

## 💡 Tema
**Profissões de Informática**

Cada dupla deve:

1. Escolher **uma profissão da área de informática**
2. Pesquisar:
   - 🎓 Universidades/faculdades que oferecem o curso
   - 🏢 Empresas que utilizam essa mão de obra
   - 💰 Salário médio da profissão

---

## 🖥️ Estrutura do Site

O site deve conter as seguintes páginas:

- `index.html`
- `profissao.html`
- `curso.htm`
- `carreira.html`
- `sobre.html`

---

## 🎨 Requisitos Técnicos

- Utilizar **HTML5**
- Utilizar **CSS3**
- Usar **CSS externo** (arquivo `.css`)
- Manter um **layout padrão** em todas as páginas
- Inserir:
  - 🖼️ Imagens
  - 📊 Gráficos (se necessário)
  - Outros elementos visuais relevantes

---

## 📱 Diferencial (Opcional)

- Aplicar o conceito de **Mobile First**  
  (site adaptado para celular primeiro)

---

## 📚 Página "Sobre"

Na página `sobre.html`, deve conter:

- Informações do(s) autor(es)
- Descrição do trabalho
- 📖 **Referências utilizadas**, seguindo a **norma ABNT**

---

## 📝 Critérios de Avaliação

Serão avaliados os seguintes itens:

### 1️⃣ Layout
- Organização visual
- Uso de cores e fontes
- Qualidade das imagens
- Organização do código e das pastas

### 2️⃣ Conteúdo
- Qualidade da pesquisa
- Clareza das informações
- Coerência com o tema

### 3️⃣ Funcionalidades
- Navegação entre páginas
- Funcionamento geral do site

### 4️⃣ Uso de HTML5 e CSS3
- Uso correto das tags
- Estrutura semântica
- Estilização adequada

### 5️⃣ Organização no GitHub
- Histórico de commits
- Participação dos dois integrantes
- Estrutura do repositório

---

## 💡 Dicas

- Não deixe para fazer tudo no último dia
- Divida as tarefas entre a dupla
- Faça commits frequentes
- Teste o site antes de entregar
